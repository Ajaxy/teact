Teact benchmark

Rendering a large tree from scratch with Teact, React and Preact. Each cell is the median time of one render, lower is better. Percentages compare with React.

This is the development server: React and Preact run their development builds here. Use npm run build and npm run preview to compare production builds.

Scenario

How it is measured

A render builds the root element with the library's createElement and renders it into an empty container; it is timed with performance.now(). React renders inside flushSync, so that it finishes within the measurement, as Teact and Preact do. After each render the container is cleared. Every 5 renders the page pauses for 100 ms and waits for an animation frame, and each library's run starts after a 1-second pause.

"30K elements" renders a list of 30,000 <li><b>1</b></li> items (median of renders). "10K components" renders 10,000 keyed product components, each with a nested button component (median of renders). All three libraries run their production builds.
