# @teact/core

**Teact** is a tiny and fast UI library with a React-like API. It powers [Telegram Web A](https://github.com/Ajaxy/telegram-tt) and [MyTonWallet](https://mytonwallet.io).

> **Status: pre-release.** `0.1.0-next` versions are published for integration testing; the API is not final.

Source, documentation and issues: https://github.com/Ajaxy/teact
