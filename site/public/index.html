Teact

A small React-like UI library that schedules DOM work in animation frames. It powers Telegram Web A and MyTonWallet. 

npm install @teact/core@next
  • Demo A small app built with the current package.
  • Benchmark Render times of Teact, React and Preact in your browser.
  • Fasterdom: Optimized Browser Rendering How Teact separates DOM measurements from mutations.
  • Documentation and source README, differences from React, and contributing, on GitHub.
